  1. Hero Slider — Banner principal con slider automático (3 slides picsum.photos), transiciones suaves, flechas y dots.
  2. Aplicaciones Institucionales — 4 accesos: Mi ISeP, SIGEDI, Gestión Cadetes, Webmail.
  3. Contadores — Estadísticas animadas: Docentes (2200+), Cadetes (1100+), Personal (800+), Aulas (500+).
  4. CTA Inscripciones — Countdown + botones de inscripción.
  5. Últimas Noticias — Noticia destacada + sidebar con links a contenido de ejemplo.
  6. Nuestras Escuelas — Grid de las 5 escuelas con escudos.
  7. Testimonios — Carrusel de 3 egresados con flechas y dots.

  • Contenido completo: excerpt destacado + cuerpo de texto.
  • ShareButton para compartir.

  • Estado 404: si el ID no existe, muestra mensaje y enlace.

18. Publicación de noticias — Guía paso a paso

18.1 Estructura de datos

{
  id: 12,
  titulo: "Título de la noticia",
  categoria: "Institucional",
  fecha: "3 DE SEPTIEMBRE, 2026",
  fechaCorta: "3 SEP",
  excerpt: "Extracto breve...",
  img: "https://picsum.photos/seed/n12/900/500"
}

18.2 Pasos para publicar

  1. Preparar imagen alusiva: 900×500 px (16:9), JPG/PNG, <200 KB.
  2. Definir categoría: Institucional | Académica | Escuelas | Eventos | Convenios.
  3. Agregar en src/data/noticias.js: nuevo objeto al array con id único.
  4. Agregar en src/data/buscador.js: entrada tipo "Noticia" para que aparezca en búsquedas.
  5. Probar: npm run dev, verificar en home, /noticias y detalle.
  6. Confirmar: npm run build + npm run lint.

18.3 Documentos adjuntos y links

  1. Subir documento a public/docs/ o usar URL externa.
  2. Agregar campo adjuntos al objeto: [{ nombre, url }].
  3. Modificar NoticiaDetalle.jsx para renderizar la sección de adjuntos.
