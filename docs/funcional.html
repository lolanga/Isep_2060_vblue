Sitio Web ISeP Santa Fe — Instituto de Seguridad Pública — Versión 1.0.0

1. Visión general

Sitio web institucional del Instituto de Seguridad Pública (ISeP) de la Provincia de Santa Fe. SPA construida con React 19 + Vite 8 + React Router 7. 100% responsive (móvil, tablet, desktop). Lazy loading por ruta para tiempos de carga optimizados.

18. Publicación de noticias — Guía paso a paso

18.1 Estructura de datos

{
  id: 14,
  titulo: "Título descriptivo",
  categoria: "Institucional",
  fecha: "4 DE SEPTIEMBRE, 2026",
  fechaCorta: "4 SEP",
  excerpt: "Extracto de 1 a 2 oraciones.",
  img: "/img/noticias/mi-imagen.jpg",  // o null
  adjuntos: [
    { nombre: "Resolución.pdf", url: "/docs/resolucion.pdf" }
  ],
  escuelas: ["policia"],
  contenido: `Primer párrafo.\n\nSegundo párrafo.`
}
Campo img: URL de imagen o null (placeholder con ícono).
Campo contenido: HTML o texto plano (\n\n para párrafos).
Campo adjuntos: Array opcional de { nombre, url }.
Campo escuelas: Array de IDs de escuelas asociadas.

18.2 Pasos para publicar

  1. Preparar imagen (4 opciones: local, externa, picsum, null). 900×500 px.
  2. Definir categoría: Institucional | Académica | Escuelas | Eventos | Convenios.
  3. Colocar adjuntos en public/docs/ (si aplica).
  4. Agregar en noticias.js con ID único.
  5. Buscador: automático (importa de noticias.js).
  6. Probar: npm run dev, verificar home, /noticias y detalle.
  7. Confirmar: npm run build + npm run lint.
