Especificaciones Funcionales

Sitio Web ISeP Santa Fe — Instituto de Seguridad Pública

1. Visión general

Sitio web institucional del ISeP construido como SPA con React 19 + Vite. Es 100% responsive (móvil, tablet, escritorio).

2. Audiencias

AudienciaNecesidadContenido
PostulantesRequisitos, convocatorias e inscripcionesIngreso
Personal en actividadTrámites, correo, sistemasMi ISeP, SIGEDI, Webmail
Público generalInformación institucionalInstitucional, Noticias
EducaciónOferta académicaFormación, Carreras, Cursos

3. Mapa de navegación

Institucional: El ISeP, Autoridades, Organización, Sedes y Contacto.

Formación: Oferta Académica, Escuelas (submenú: Policía, Especialidades, Investigaciones, Superior, Educación a Distancia), Carreras, Cursos.

Ingreso: Convocatorias, Inscripciones, Información para postulantes.

Últimas noticias: link directo a /noticias.

Mi ISeP: botón siempre visible.

6. Flotantes y redes

  • Botón WhatsApp flotante, siempre visible (abre conversación).
  • Redes: Facebook, YouTube, Instagram y TikTok.

7. Requisitos obligatorios

  • Responsive obligatorio en todos los dispositivos.
  • Contraste legible del texto sobre imágenes.
  • Mi ISeP siempre visible en móvil.
  • Consistencia visual del gradiente institucional.

8. Disponibilidad

npm install → npm run dev (puerto 5173). Build: npm run build.
