Sitio Web ISeP Santa Fe — Instituto de Seguridad Pública

1. Visión general

Sitio web institucional del Instituto de Seguridad Pública (ISeP) de la Provincia de Santa Fe, construido como SPA con React 19 + Vite + React Router. Es 100% responsive (móvil, tablet, escritorio).

4. Funcionalidades implementadas (Home)

  1. Hero Slider — banner principal con slider automático (3 slides), transiciones suaves, flechas de navegación y indicadores (dots). Se pausa al pasar el cursor.
  2. Últimas Noticias — destacada + lateral + Calendario Académico.
  3. Aplicaciones Institucionales — Mi ISeP, SIGEDI, Webmail.
  4. Nuestras Escuelas — 4 escuelas, cada una con su escudo institucional.
  5. CTA Inscripciones — llamado a la acción.

Hero Slider

  • Slides: 3 slides con imagen, badge, título y descripción.
  • Automático: cambia cada 6 segundos.
  • Pausa: al pasar el cursor sobre el hero.
  • Navegación: flechas izquierda/derecha + indicadores (dots) en la parte inferior.
  • Transiciones: fade suave entre slides (1s ease-in-out).

Página de Noticias (/noticias)

  • Filtro por categorías (sticky), noticia principal, historial con paginación (10 pág.), estados vacíos. Categoría activa con gradiente.

5. Formación

Oferta Académica

Vista dinámica en pestañas desde datos mock: Carreras, Cursos y Convocatorias.

Carreras (/institucional/carreras)

Cada carrera muestra: Nombre, Escuela, Descripción, Duración, Modalidad, Requisitos y Documentos relacionados.

Cursos (/secretaria/cursos)

  • Filtros por Escuela, Tipo y Estado.
  • Agrupados en Actuales, Próximos e Historial (finalizados).
  • Cada curso es un acordeón con Nombre, Tipo, Información, Período y botón "Acceso a Mi ISeP".

Páginas de escuela (plantilla común)

  • Logo (escudo), Presentación, Información (categoría, duración, modalidad, sede), Carreras, Cursos actuales (acceso a Mi ISeP), Noticias y Contacto. Aplicada a las 5 escuelas.

8. Accesos flotantes, redes y footer

  • WhatsApp flotante siempre visible (esquina inferior derecha).
  • Buscador funcional: en la barra de navegación, al lado del botón "Mi ISeP". Indexa escuelas, carreras, cursos, convocatorias y páginas institucionales. Resultados dinámicos con ícono, título, subtítulo y categoría.
  • Íconos en navegación: cada sección del menú tiene un ícono de Material Symbols (Institucional → account_balance, Formación → school, Ingreso → login, Últimas noticias → newspaper).
  • Redes: Facebook, YouTube, Instagram y TikTok.
  • Footer rediseñado: Identidad institucional · Accesos principales · Contacto · Sedes (Alem 2050 y RN11 km 482 Recreo) · Enlaces institucionales. Fondo decorativo que se integra con el fondo general.
  • Créditos: "Departamento Desarrollo, Tecnología e Innovación" + fecha dinámica.

9. Requisitos funcionales obligatorios

  1. Responsive obligatorio (móvil, tablet, desktop).
  2. Contraste legible del texto sobre imágenes (overlays con scrim oscuro).
  3. Mi ISeP siempre visible.
  4. Logo ISeP enlazable que vuelve al inicio (/).
  5. Consistencia visual del sistema de gradiente y glow.
  6. Fondo decorativo global: background-attachment: fixed, color base #bcd8db y gradientes radiales/lineales.

10. Disponibilidad

npm install → npm run dev (http://localhost:5173). Build: npm run build → npm run preview. Lint: npm run lint.
