3. Sistema de diseño

Tokens clave

--primary #00254d
--secondary #0055c9
--gradient-primary linear-gradient(90deg, #227bd1, #17be95)
--gradient-glow 0 6px 18px #1bb4c373
--gradient-hover-lift translateY(-1px)
--color-start #227bd1 / --color-end #17be95

Gradiente institucional (uniforme)

Centralizado en --gradient-primary. Se aplica a:

  • Botones: btn-cta, btn-cta-light, btn-isep, btn-download.
  • Activos: filtro-btn--active, pag-num--active.
  • Hover nav: nav-link, dropdown trigger, dropdown-item (fondo + texto blanco + glow).
  • Hover cards: school, app, card, mini-card, hcard (sombra + borde).
  • Overlays: gradiente + scrim oscuro para contraste.

Overlay con contraste

background:
  linear-gradient(to right, rgba(0,21,43,0.88), rgba(0,37,77,0.72) 45%, ...),
  var(--gradient-primary);
